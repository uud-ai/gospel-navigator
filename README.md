# Благовест

Telegram Mini App: ИИ-чат по Евангелию на русском языке. Одностраничное
приложение (`index.html`) с 14 темами (`topics.js`), «стихом дня»
(`verses_of_day.js`, 40 стихов) и чатом, который отвечает на вопросы о
Евангелии, опираясь на синодальный текст и толкования блж. Феофилакта
Болгарского.

Приложение не заменяет беседу со священником и не даёт пастырских
советов — это инструмент для изучения текста Писания.

## Как запустить

- **Telegram Mini App** — предполагаемый способ использования. `index.html`
  нужно разместить на статическом хостинге (GitHub Pages, Netlify и т.п.) и
  подключить как Web App через `@BotFather` (`/newapp`).
- **Обычный браузер** — `index.html` можно открыть напрямую: Telegram-слой
  (`telegram-web-app.js`) не обязателен, интерфейс и темы работают и вне
  Telegram. Чат с ИИ работает в обоих случаях одинаково — это просто фронтенд
  поверх облачной функции (см. раздел «Backend» ниже).

Сборки/транспиляции не требуется — это обычный HTML/JS без фреймворков.

## Структура репозитория

```
index.html          — вся клиентская логика (UI, чат, работа с темами)
topics.js            — 14 тем, каждая со ссылками на стихи и вступлением
verses_of_day.js     — 40 стихов «на каждый день», ротация по дате
data/
  bible.json                  — весь Новый Завет (27 книг), синодальный
                                 перевод, 7955 стихов
  commentaries.json           — толкования блж. Феофилакта на 4 Евангелия,
                                 3734 фрагмента
  bible_embeddings.json       — эмбеддинги СТАРОЙ версии bible.json
                                 (только Евангелия) — сейчас не соответствуют
                                 файлу выше, см. «Backend»
  commentaries_embeddings.json — эмбеддинги толкований
scripts/
  get_nt.py                        — собирает data/bible.json (весь НЗ) из внешнего репозитория
  build_commentaries.js           — собирает data/commentaries.json с azbyka.ru
  build_commentaries_embeddings.js — считает эмбеддинги для commentaries.json
backend/
  worker.js             — облачная функция чата (Cloudflare Workers)
  wrangler.toml         — конфигурация воркера (переменные, секреты)
  README.md             — статус, переменные окружения, что ещё не сделано
```

## Backend

Код облачной функции — `backend/worker.js`, написан с нуля (исходник, на
который ссылались старые сборочные скрипты, был утерян при создании проекта
и не восстанавливается). Контракт запроса/ответа сохранён таким, каким его
ожидает `index.html` (`FUNCTION_URL` / `APP_TOKEN` там не менялись).

Платформа — **Cloudflare Workers**. Данные (`data/*.json`) воркер читает
прямо с `raw.githubusercontent.com` на этот же публичный репозиторий — R2
не используется (Cloudflare просит привязать карту даже для бесплатного
тарифа R2, решили не заводить лишнюю зависимость, раз данные и так
публичны). Изначально пробовали Yandex Cloud Functions, но аккаунт
оказался заблокирован по неоплаченному балансу ещё до первого деплоя —
перешли на Cloudflare.

**Не задеплоено, не проверено вживую.**
Подробности, переменные окружения и список того, что нужно сделать перед
первым запуском — в `backend/README.md`.

В репозитории по-прежнему нет скрипта, которым был посчитан
`data/bible_embeddings.json` (только для `commentaries_embeddings.json`
скрипт есть) — формат и факт использования `text-embedding-3-small`
(512 измерений) известны со слов автора, но воспроизвести файл с нуля
сейчас нечем.

**`data/bible_embeddings.json` сейчас устарел относительно `data/bible.json`.**
При загрузке полного Нового Завета (см. «Известные пробелы») заодно
исправлен баг старого скрипта (пропущенные стихи в 11 главах Евангелий —
см. git-историю `data/bible.json`), из-за чего индексы стихов в файле
сдвинулись, а 23 новые книги вообще не заэмбеддены. Поиск по эмбеддингам в
`worker.js` будет возвращать нерелевантные/смещённые фрагменты, пока
`bible_embeddings.json` не пересчитан с нуля под новый `bible.json` —
платный шаг, выполняется отдельно по команде автора.

## Известные пробелы (не инвентаризация обещаний, а факты по состоянию репозитория)

- **Скрипт для `bible_embeddings.json` отсутствует**, а сам файл сейчас
  устарел — см. «Backend».
- Все 47 ссылок в `topics.js` и все 40 в `verses_of_day.js` автоматически
  сверены с `data/bible.json` после загрузки полного НЗ — ссылки находятся.
  Это проверка существования (книга/глава/стих есть в тексте), не сверка
  слово-в-слово процитированного текста с оригиналом — последнее отдельная
  задача.

## Пересборка данных

```bash
npm run build:nt                       # python scripts/get_nt.py
npm run build:commentaries             # node scripts/build_commentaries.js — ходит на azbyka.ru, НЕ запускать без необходимости
PROXY_API_KEY=xxx npm run build:commentaries-embeddings  # платный API, НЕ запускать без необходимости
```

`build_commentaries.js` делает одну последовательную выгрузку с azbyka.ru с
задержкой 1.5 с между запросами — не предназначен для повторных прогонов.
`build_commentaries_embeddings.js` требует переменную окружения
`PROXY_API_KEY` и обращается к платному API.
